## 使用示例

### 启动 llama-cpp-python 后端

```bash
# 激活虚拟环境
.\venv\Scripts\Activate.ps1

# 启动后端
python python/start_llama_cpp.py
```

### 启动网关

```bash
go run cmd/inference/main.go
```

### 测试

```bash
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tinyllama-chat",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

## 核心优势

1. **插件化**: 后端完全解耦，新增插件无需修改核心
2. **配置驱动**: 通过 YAML 控制插件启用/禁用
3. **标准接口**: 统一的 Plugin 接口，降低集成成本
4. **生命周期管理**: Init/Health/Close 完整生命周期
5. **云原生**: 适合容器化和 K8s 部署

## 配置说明

编辑 `config.yaml` 切换后端：

```yaml
plugins:
  llama-cpp:
    enabled: true      # 启用 llama-cpp
    base_url: "http://localhost:8000"
    models:
      - "tinyllama-chat"

  ollama:
    enabled: false     # 禁用 Ollama
    base_url: "http://localhost:11434"
    models:
      - "llama3.1:8b"
```

重启服务即可生效，无需修改代码。
