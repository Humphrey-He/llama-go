# llama-go 插件化架构设计

## 架构概览

llama-go 采用"内核插件化，接口标准化"的设计，实现云原生推理网关。

```
┌─────────────────────────────────────┐
│      Gateway Core (Go)              │
│  - OpenAI Compatible API            │
│  - Plugin Manager                   │
│  - Model Registry                   │
│  - Config Loader                    │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│    Standard Plugin Interface        │
│  - Generate / GenerateStream        │
│  - Health / Init / Close            │
│  - Metadata (Name/Version/Type)     │
└─────────────────────────────────────┘
       ↓              ↓              ↓
┌──────────┐   ┌──────────┐   ┌──────────┐
│llama-cpp │   │  Ollama  │   │   vLLM   │
│  Plugin  │   │  Plugin  │   │  Plugin  │
└──────────┘   └──────────┘   └──────────┘
```

## 核心组件

### 1. Plugin Interface (`internal/plugin/interface.go`)

标准化的插件接口：

```go
type Plugin interface {
    // 推理能力
    Generate(ctx, req) (*GenerateResponse, error)
    GenerateStream(ctx, req) (<-chan StreamChunk, error)

    // 生命周期
    Init(ctx, config) error
    Close() error
    Health(ctx) error

    // 元数据
    Name() string
    Version() string
    Type() string
}
```

### 2. Plugin Manager (`internal/plugin/manager.go`)

插件生命周期管理：
- 注册/获取插件
- 批量初始化
- 健康检查
- 优雅关闭

### 3. Config Loader (`internal/config/loader.go`)

YAML 配置驱动：

```yaml
plugins:
  llama-cpp:
    enabled: true
    base_url: "http://localhost:8000"
    models:
      - "tinyllama-chat"
```

## 已实现插件

### llama-cpp-python (`internal/plugin/llamacpp/`)
- 支持 GGUF 格式
- GPU 加速（CUDA）
- 适合本地部署

### Ollama (`internal/plugin/ollama/`)
- 流式生成
- 多模型支持
- 社区生态

### vLLM (`internal/plugin/vllm/`)
- 高性能推理
- PagedAttention
- 生产级部署

## 使用方式

### 1. 配置插件

编辑 `config.yaml`：

```yaml
server:
  port: 8080

plugins:
  llama-cpp:
    enabled: true
    base_url: "http://localhost:8000"
    models:
      - "tinyllama-chat"
```

### 2. 启动服务

```bash
go run cmd/inference/main.go
```

### 3. 调用 API

```bash
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tinyllama-chat",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

## 添加新插件

### 步骤 1: 实现接口

```go
package myplugin

import "llama-go/internal/plugin"

type Plugin struct {
    baseURL string
}

func New() plugin.Plugin {
    return &Plugin{}
}

func (p *Plugin) Init(ctx context.Context, config map[string]interface{}) error {
    p.baseURL = config["base_url"].(string)
    return nil
}

// 实现其他接口方法...
```

### 步骤 2: 注册插件

在 `cmd/inference/main.go` 中：

```go
pluginFactories := map[string]func() plugin.Plugin{
    "llama-cpp": llamacpp.New,
    "ollama":    ollama.New,
    "myplugin":  myplugin.New,  // 添加这行
}
```

### 步骤 3: 配置启用

在 `config.yaml` 中：

```yaml
plugins:
  myplugin:
    enabled: true
    base_url: "http://localhost:9000"
    models:
      - "my-model"
```

## 优势

1. **解耦**: 核心与插件分离，易于维护
2. **扩展**: 新增后端无需修改核心代码
3. **配置驱动**: 运行时切换后端
4. **标准化**: 统一接口，降低集成成本
5. **云原生**: 支持容器化、K8s 部署
